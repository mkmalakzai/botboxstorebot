# TPL-003 — Professional Store & Order Bot

Platform: **Bots.Business**

Complete V1 command architecture for BOTBOX: user storefront, cart, checkout, orders, wishlist/profile and a multi-admin business control center. Run `setup` once as creator, then `/start`.

All store/business values are stored in Bot/User properties and are configurable from commands/admin flows; no token or merchant account is embedded in source.
